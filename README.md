# intro-profession

Практические занятия 1-2 курса «Введение в профессию».

Учебный проект показывает базовый рабочий цикл Git (репозиторий, commit, ветки, merge), отправку REST-запроса к **OMDb API**, а также работу с большой языковой моделью (**GigaChat**) через API и библиотеку **LangChain**.

## Что такое OMDb API

OMDb API — веб-сервис для поиска информации о фильмах и сериалах по названию. Он возвращает данные в формате JSON: название, год выпуска, жанр, режиссёра, актёров, рейтинг и краткое описание фильма. Ключ доступа выдаётся на https://www.omdbapi.com/.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `rest_api_demo.ipynb` | Ноутбук с запросом к OMDb API и извлечением полей о фильме |
| `llm_work.ipynb` | Ноутбук занятия 2: извлечение количества проживающих из заявок через GigaChat и оценка точности |
| `llm_structured.ipynb` | Структурированный JSON-вывод (ветка `llm-improve-2`) и оценка точности по полям |
| `rental_19.csv` | Датасет варианта 19: тексты заявок и эталонное количество проживающих |
| `reflection1.md`, `reflection2.md` | Рефлексии по занятиям |
| `.gitignore` | Исключения: `.env`, `.venv/`, `__pycache__/`, `.ipynb_checkpoints/` |

## Ветки

- `master` — базовые версии решений занятий 1 и 2.
- `movie-output-feature` — небольшое улучшение вывода (вывод актёров и красивый итоговый вывод), влито в `master`.
- `env-feature` — более профессиональный вариант хранения ключа через `.env`; здесь же создан ноутбук `llm_demo.ipynb`.
- `llm-improve-1` — расчёт точности системы через pandas и сравнение техник промптирования, влито в `master`.
- `llm-improve-2` — структурированный JSON-вывод; в `master` не вливается.

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install requests ipykernel pandas python-dotenv langchain-gigachat
   ```

2. Для работы с LLM создайте в корне файл `.env` с ключом GigaChat:

   ```
   GIGA_KEY=ваш_ключ
   ```

   Файл `.env` добавлен в `.gitignore` и в репозиторий не попадает.

3. Откройте `rest_api_demo.ipynb` или `llm_work.ipynb`, выберите ядро `.venv` и запустите ячейки сверху вниз.

## Безопасность

API-ключи нельзя хранить в коде или коммитить в публичный репозиторий. Ключ GigaChat читается из файла `.env` (переменная `GIGA_KEY`), который добавлен в `.gitignore`.
