# intro-profession

Практическое занятие 1 курса «Введение в профессию».
Тема: **«Репозитории и интеграции»**.

Учебный проект показывает базовый рабочий цикл Git (репозиторий, commit, ветки, merge) и отправку REST-запроса к **OMDb API** из Python с разбором ответа в формате JSON.

## Что такое OMDb API

OMDb API — веб-сервис для поиска информации о фильмах и сериалах по названию. Он возвращает данные в формате JSON: название, год выпуска, жанр, режиссёра, актёров, рейтинг и краткое описание фильма. Ключ доступа выдаётся на https://www.omdbapi.com/.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `rest_api_demo.ipynb` | Ноутбук с запросом к OMDb API и извлечением полей о фильме |
| `reflection1.md` | Рефлексия по занятию |
| `.gitignore` | Исключения: `.env`, `.venv/`, `__pycache__/`, `.ipynb_checkpoints/` |

## Ветки

- `master` — базовая версия: API-ключ вводится вручную и не сохраняется в коде.
- `movie-output-feature` — небольшое улучшение вывода (вывод актёров и красивый итоговый вывод), влито в `master`.
- `env-feature` — более профессиональный вариант хранения ключа через `.env`. В `master` не вливается.

## Запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install requests ipykernel
   ```

2. Для ветки `env-feature` дополнительно установите `python-dotenv`:

   ```powershell
   python -m pip install python-dotenv
   ```

3. Откройте `rest_api_demo.ipynb`, выберите ядро `.venv` и запустите ячейки сверху вниз.

## Безопасность

API-ключ нельзя хранить в коде или коммитить в публичный репозиторий. В ветке `env-feature` ключ читается из файла `.env`, который добавлен в `.gitignore`.
